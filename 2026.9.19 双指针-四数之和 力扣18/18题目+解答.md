# LeetCode 18 四数之和

日期：2026.09.19

## 题目描述

给你一个由 `n` 个整数组成的数组 `nums` ，和一个目标值 `target` 。请你找出并返回满足下述全部条件且不重复的四元组 `[nums[a], nums[b], nums[c], nums[d]]`（若两个四元组元素一一对应，则认为两个四元组重复）：

- `0 <= a, b, c, d < n`
- `a、b、c 和 d` 互不相同
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

你可以按 **任意顺序** 返回答案。

**示例 1：**

输入：`nums = [1,0,-1,0,-2,2], target = 0`  
输出：`[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]`

**示例 2：**

输入：`nums = [2,2,2,2,2], target = 8`  
输出：`[[2,2,2,2]]`

**提示：**

- `1 <= nums.length <= 200`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

## ✅ AC最终代码（带详细注释）

```cpp
//2026.9.19
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        // res 存放所有不重复四元组结果
        vector<vector<int>> res;
        int n = nums.size();

        // 不足 4 个数，不可能组成四元组
        if (n < 4) return res;

        // 排序：双指针和去重的前提
        sort(nums.begin(), nums.end());

        // 第一层循环：固定第一个数 nums[i]
        for (int i = 0; i < n - 3; i++) {
            // 对 nums[i] 去重：和前一个数相同，说明这个数已经作为第一个数处理过
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            // 第二层循环：固定第二个数 nums[j]
            for (int j = i + 1; j < n - 2; j++) {
                // 对 nums[j] 去重：注意是 j > i + 1
                // 表示对于当前 i，j 的第一个位置不能跳过，之后的重复才跳过
                if (j > i + 1 && nums[j] == nums[j - 1]) {
                    continue;
                }

                // 双指针：在 j 后面寻找剩下两个数
                int left = j + 1;
                int right = n - 1;

                while (left < right) {
                    // 四个 int 相加可能溢出 int，必须转 long long
                    long long sum = (long long)nums[i] + nums[j] + nums[left] + nums[right];

                    if (sum < target) {
                        // 和太小，左指针右移增大和
                        left++;
                    } else if (sum > target) {
                        // 和太大，右指针左移减小和
                        right--;
                    } else {
                        // 找到一组合法四元组
                        res.push_back({nums[i], nums[j], nums[left], nums[right]});

                        // 对第三个数 nums[left] 去重
                        while (left < right && nums[left] == nums[left + 1]) {
                            left++;
                        }

                        // 对第四个数 nums[right] 去重
                        while (left < right && nums[right] == nums[right - 1]) {
                            right--;
                        }

                        // 去重完成后，仍然需要收缩指针，寻找下一组解
                        left++;
                        right--;
                    }
                }
            }
        }

        return res;
    }
};
```

## 🧠 思路推导

1. 暴力思路：四层循环枚举所有四元组，再去重。时间复杂度 `O(n^4)`，会超时，不可采用。
2. 优化核心：**排序 + 双指针**
   - 先对数组排序，排序后相同元素相邻，方便去重；同时可以利用有序性移动指针。
   - 固定前两个数：`nums[i]` 和 `nums[j]`。
   - 剩余两个数用双指针寻找：`left = j + 1`，`right = n - 1`。
   - 计算四数之和：
     - `sum < target`：和太小，`left++`；
     - `sum > target`：和太大，`right--`；
     - `sum == target`：收集答案，然后对 `left`、`right` 去重，再同时收缩指针。

3. 去重逻辑：
   - 第一个数 `nums[i]` 去重：`i > 0 && nums[i] == nums[i - 1]`，跳过；
   - 第二个数 `nums[j]` 去重：`j > i + 1 && nums[j] == nums[j - 1]`，跳过；
   - 第三、第四个数在找到合法答案后，用 `while` 跳过相邻重复值。

> ⚠️关键细节

1. **四数之和的 `target` 是任意值，不能像三数之和那样直接写 `if (nums[i] > target) return res;` 剪枝。**  
   三数之和 `target == 0`，`nums[i] > 0` 可以直接结束；但四数之和 `target` 可能为负数，简单比较 `nums[i] > target` 会漏解。

2. **第一个数去重条件：`i > 0 && nums[i] == nums[i - 1]`。**  
   表示当前数已经作为第一个数处理过，跳过本轮。

3. **第二个数去重条件：`j > i + 1 && nums[j] == nums[j - 1]`。**  
   注意是 `j > i + 1`，不是 `j > 0`。因为对于当前固定的 `i`，`j = i + 1` 是第一个可选的第二个数，不能跳过。

4. **左右指针去重必须写在找到合法四元组之后。**  
   如果提前去重，可能漏掉合法答案，例如 `[2,2,2,2]` 这种由重复元素组成的解。

5. **去重 `while` 结束后，仍然要执行 `left++` 和 `right--`。**  
   否则会停留在当前重复值上，造成死循环或重复结果。

6. **使用 `long long` 防止溢出。**  
   `nums[i]` 最大 `10^9`，四个数相加最大约 `4 * 10^9`，超过 `int` 范围。

7. **可以提前判断 `n < 4`，并让循环边界为 `i < n - 3`、`j < n - 2`。**  
   避免进入不可能组成四元组的位置，减少无效循环。

### 易混题目区分

1. LeetCode 15 三数之和：**同一个数组选 3 个元素，`target == 0`，排序 + 双指针，时间复杂度 `O(n^2)`**。
2. LeetCode 18 四数之和：**同一个数组选 4 个元素，`target` 任意，排序 + 双指针，时间复杂度 `O(n^3)`**。
3. LeetCode 454 四数相加 II：**4 个独立数组，不要求下标互异，折半枚举 + `unordered_map` 哈希，时间复杂度 `O(n^2)`**。

## 📊 复杂度分析

- 时间复杂度：`O(n^3)`。  
  排序 `O(n log n)`；外层 `i` 遍历 `O(n)`，内层 `j` 遍历 `O(n)`，内层双指针 `O(n)`，合计 `O(n^3)`。排序被低阶吸收。

- 空间复杂度：`O(log n)`。  
  主要是排序递归栈空间；结果数组不计入算法额外空间开销。

## 💡 学到的知识点

1. **多数之和通用套路：排序 + 多层固定 + 双指针。**
   - 三数之和：固定 1 个数 + 双指针；
   - 四数之和：固定 2 个数 + 双指针；
   - 五数之和：固定 3 个数 + 双指针，以此类推。

2. **去重两套逻辑：**
   - 固定数去重：在对应循环开头，和前一个数比较；
   - 双指针去重：找到合法答案后，用 `while` 跳过重复值。

3. **四数之和不能照搬三数之和的剪枝。**
   三数之和 `target == 0`，可以 `nums[i] > 0` 直接返回；四数之和 `target` 任意，必须用“最小四数和 / 最大四数和”判断。

4. **防溢出：`int` 相加可能溢出，转 `long long`。**

5. **易错点：**
   - `j` 去重写成 `j > 0 && nums[j] == nums[j - 1]`，会漏解；
   - 左右指针去重放在 `while` 开头，会漏解；
   - 找到答案后忘记 `left++`、`right--`；
   - 忘记 `long long` 导致溢出。

## ✨ 拓展思考

1. **剪枝优化版本**

   四数之和可以加剪枝，减少无效枚举。剪枝不会改变最坏复杂度，仍然是 `O(n^3)`，只是减少常数。

```cpp
// 剪枝版本
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> res;
        int n = nums.size();
        if (n < 4) return res;

        sort(nums.begin(), nums.end());

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            // 当前 i 下最小四数和都大于 target，后面 i 更大，更不可能
            if ((long long)nums[i] + nums[i + 1] + nums[i + 2] + nums[i + 3] > target)
                break;

            // 当前 i 下最大四数和都小于 target，i 需要增大
            if ((long long)nums[i] + nums[n - 1] + nums[n - 2] + nums[n - 3] < target)
                continue;

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                // 当前 i,j 下最小四数和都大于 target，j 增大更不可能
                if ((long long)nums[i] + nums[j] + nums[j + 1] + nums[j + 2] > target)
                    break;

                // 当前 i,j 下最大四数和都小于 target，j 需要增大
                if ((long long)nums[i] + nums[j] + nums[n - 1] + nums[n - 2] < target)
                    continue;

                int left = j + 1;
                int right = n - 1;

                while (left < right) {
                    long long sum = (long long)nums[i] + nums[j] + nums[left] + nums[right];

                    if (sum < target) {
                        left++;
                    } else if (sum > target) {
                        right--;
                    } else {
                        res.push_back({nums[i], nums[j], nums[left], nums[right]});

                        while (left < right && nums[left] == nums[left + 1]) left++;
                        while (left < right && nums[right] == nums[right - 1]) right--;

                        left++;
                        right--;
                    }
                }
            }
        }

        return res;
    }
};
```

2. **为什么剪枝有效？**
   - 排序后，最小四数和都大于 `target`，说明后面只会更大，可以直接 `break`；
   - 最大四数和都小于 `target`，说明当前固定值太小，需要增大，可以 `continue`。

3. **面试建议**
   - 优先保证正确性、去重完整、边界安全；
   - 剪枝是加分项，不是必须项；
   - 如果时间紧或容易写错，先写基础版 `O(n^3)` 即可；
   - 如果面试官要求优化，再补充最小和 / 最大和剪枝。
