# LeetCode 15 三数之和

日期：2026.09.14

## 题目描述

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k`、`j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。

> 
> 注意：答案中不可以包含重复的三元组。

**示例 1：**
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]

**示例 2：**
输入：nums = [0,1,1]
输出：[]

**示例 3：**
输入：nums = [0,0,0]
输出：[[0,0,0]]

**提示：**

- $3 \le nums.length \le 3000$
- $-10^5 \le nums[i] \le 10^5$

## ✅ AC最终代码（带详细注释）

```cpp
//2026.9.14
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        // res 存放最终所有不重复三元组结果
        vector<vector<int>> res;
        // 第一步：数组排序，排序是双指针和去重的前提，相同元素会相邻
        sort(nums.begin(), nums.end());

        // 外层循环：固定三元组第一个元素 a = nums[i]
        for (int i = 0; i < nums.size(); i++) {
            // 剪枝：数组升序，如果a已经大于0，后面b、c都>=a，三数之和必然>0，直接结束
            if (nums[i] > 0) {
                return res;
            }

            // 对a去重：i>0防止下标越界；和前一个元素相等，代表该a已经处理过，跳过本轮
            // 注意：只能和i-1对比，不能和i+1对比，否则会漏掉合法解如[-1,-1,2]
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            } 

            // 定义双指针
            // left 指向a的下一个位置，作为第二个数b
            int left = i + 1;
            // right指向数组末尾，作为第三个数c
            int right = nums.size() - 1;

            // 双指针循环，条件right > left，保证三个下标 i < left < right，下标不能重合
            while (right > left) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum > 0) {
                    // 三数之和大于0，总和太大，需要变小，右指针左移
                    right--;
                } else if (sum < 0) {
                    // 三数之和小于0，总和太小，需要变大，左指针右移
                    left++;
                } else {
                    // sum == 0，找到一组合法三元组，加入结果集
                    res.push_back(vector<int> {nums[i], nums[left], nums[right]});

                    // 对b去重：找到答案之后再去重，跳过left后面所有和当前left相等的元素
                    // 必须放在得到解之后，不能放在while开头，防止丢失[0,0,0]这类解
                    while (right > left && nums[left] == nums[left + 1]) {
                        left++;
                    }
                    // 对c去重：跳过right前面所有和当前right相等的元素
                    while (right > left && nums[right] == nums[right - 1]) {
                        right--;
                    }

                    // 去重完成，指针同时收缩，寻找下一组可能的b、c
                    left++;
                    right--;
                }
            }
        }
        return res;
    }
};
```

## 🧠 思路推导

1. 暴力思路：三层循环枚举所有三元组，再去重。时间复杂度 $O(n^3)$，同时去重操作开销大，会超时，不可采用。
2. 优化核心：**排序 + 双指针**
   - 先对数组排序，排序后相同元素相邻，方便做去重；从小到大有序，可以利用大小关系移动指针。
   - 固定第一个元素 $a = nums[i]$，再用双指针：`left = i+1`，`right = n‑1`，分别代表第二个元素b、第三个元素c。
   - 计算三数之和：
     - 和大于0：总和偏大，`right--` 减小总和；
     - 和小于0：总和偏小，`left++` 增大总和；
     - 和等于0：收集该三元组，然后对b、c去重，再同时移动左右指针。

> 
> ⚠️关键细节

1. `if(nums[i] > 0) return res;`：数组升序，a已经大于0，则后面b、c都≥a>0，三数之和一定大于0，可以直接返回结果，剪枝。
2. `if (i > 0 && nums[i] == nums[i‑1]) continue;`：**对a去重**。已经用相同的a值处理过一轮，跳过，防止产出重复三元组；必须和前一位`i‑1`对比，不能和后一位`i+1`对比，否则会漏掉合法答案。
3. b、c的去重`while`循环**写在找到合法三元组之后**，不能写在while循环开头。如果提前去重会丢失例如`[0,0,0]`这类合法三元组。
4. 去重while结束之后，依旧需要执行`left++`、`right--`，收缩窗口继续寻找下一组解。

### 易混题目区分

1. LeetCode 15 三数之和：**同一个数组选3个元素，不能输出重复三元组，排序+双指针**。
2. LeetCode 454 四数相加II：**4个独立数组，不限制下标，折半枚举+unordered_map哈希**。

## 📊 复杂度分析

- 时间复杂度：$O(n^2)$。排序 $O(n\log n)$；外层for循环遍历n次，内层双指针每个元素最多访问一次，合计$O(n^2)$，$n\log n$被低阶忽略。
- 空间复杂度：$O(\log n)$，排序需要栈空间；结果数组不计入算法额外空间开销。

## 💡学到的知识点

1. **排序+双指针**：适合数组内多求和、需要去重的问题；排序是去重的前提。
2. 去重两套逻辑：
   - a去重：在外层for循环开头，`i>0 && nums[i]==nums[i‑1] continue;`
   - b、c去重：**找到一组答案之后**用while循环跳过重复值。
3. 剪枝：当固定的a已经>0，直接return，减少循环次数。
4. 易错坑点：
   - a去重不能写成`nums[i]==nums[i+1]`，会漏掉合法解；
   - b、c的去重while不能放到while循环最开头；
   - 完成b、c的while去重之后，仍然要手动执行`left++`、`right--`。

## ✨拓展思考

1. 为什么不用哈希表？三数之和要求去重，哈希实现去重逻辑复杂，不如排序双指针简洁高效。
2. 四数之和(LeetCode18)：是本题的延伸，多一层外层循环，同样遵循排序、第一层元素去重、第二层元素去重、内层双指针的套路。
