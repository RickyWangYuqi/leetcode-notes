# LeetCode 383 赎金信

日期：2026.09.14

## 题目描述

给你两个字符串：`ransomNote` 和 `magazine` ，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。

如果可以，返回 `true` ；否则返回 `false`。

`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。

**示例 1：**
输入：ransomNote = "a", magazine = "b"
输出：false

**示例 2：**
输入：ransomNote = "aa", magazine = "ab"
输出：false

**示例 3：**
输入：ransomNote = "aa", magazine = "aab"
输出：true

**提示：**

- $1 \le \text{ransomNote.length}, \text{magazine.length} \le 10^5$
- `ransomNote` 和 `magazine` 由小写英文字母组成

## ✅ AC最终代码（版本一 unordered_map哈希写法）

```cpp
//2026.9.14
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        // 剪枝：赎金信更长直接不可能
        if (ransomNote.size() > magazine.size()) {
            return false;
        }
        unordered_map <char, int> mp;
        // 统计magazine每个字符出现次数
        for (char c : magazine) {
            mp[c]++;
        }
        // 消耗字符，每用一个计数减一
        for (char c : ransomNote) {
            // 字符不存在或者已经用完
            if (mp.find(c) == mp.end() || mp[c] == 0) {
                return false;
            }
            mp[c]--;
        }
        return true;
    }
};
```

## ✅ AC最终代码（版本二 数组哈希最优写法 $(O(n))$）

```cpp
//2026.9.14
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        if (ransomNote.size() > magazine.size()) return false;
        int cnt[26] = {0};
        //统计magazine字符频次
        for (char c : magazine) {
            cnt[c - 'a']++;
        }
        //消耗字符
        for (char c : ransomNote) {
            cnt[c - 'a']--;
            //减完为负数代表字符不够用
            if (cnt[c - 'a'] < 0) {
                return false;
            }
        }
        return true;
    }
};
```

## ✅ AC最终代码（版本三 数组哈希和map逻辑对齐版本）

```cpp
//2026.9.14
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        if (ransomNote.size() > magazine.size()) return false;
        int cnt[26] = {0};
        for (char c : magazine) cnt[c-'a']++;
        for (char c : ransomNote) {
            if (cnt[c-'a'] == 0) return false;
            cnt[c-'a']--;
        }
        return true;
    }
};
```

## 🧠 思路推导

1. 题意核心：`ransomNote`的每一个字符，在`magazine`中要有足够数量，每个字符只能用一次。
2. 剪枝优化：如果`ransomNote`字符串长度大于`magazine`，直接返回false，不可能拼成。
3. 哈希计数思路：
   - 统计`magazine`中各个字符出现频次；
   - 再遍历`ransomNote`，每遇到一个字符就消耗一次频次；
   - 一旦某个字符频次不够，直接返回false；全部遍历完成返回true。

> 
> ⚠️关键细节：
> 本题字符集限定**仅26个小写英文字母**，可以用数组做哈希；数组哈希效率高于`unordered_map`。
> 
> 
> - map版本：需要`find`判断key是否存在，还要判断计数等于0；
> - 数组版本：不存在的字符初始计数为0，自减后直接变成负数，以此判断字符不足。

### 两种哈希方案对比

| 对比项 | unordered_map版本 | 数组哈希版本 |
| --- | --- | --- |
| 底层结构 | 哈希表，存在哈希冲突 | 连续静态数组，下标直接寻址 |
| 时间复杂度 | $(O(n))$，常数开销大 | $(O(n))$，常数极小，本题最优 |
| 空间复杂度 | $(O(k))$，k为出现字符种类 | 固定$(O(26)=(O(1)))$常量空间 |
| 适用场景 | 字符集大，字符不确定 | **字符集已知且范围很小** |
| 代码细节 | 需要find判断key是否存在 | 利用`c-'a'`完成字符到下标的映射，无需查找 |

> 
> 易混题目区分
> 
> 
> 1. 383 赎金信：只有26个小写字母，优先数组哈希；
> 2. 242 有效的字母异位词：同样26小写字母，同样优先数组哈希；
> 3. 454 四数相加II：key是int数值，范围很大，只能使用unordered_map。

## 📊 复杂度分析

- unordered_map版本
  - 时间复杂度：$(O(m+n))$，m、n分别为两个字符串长度；哈希查找平均$(O(1))$
  - 空间复杂度：$(O(k))$，k为magazine中出现不同字符数量，最多26
- 数组哈希版本
  - 时间复杂度：$(O(m+n))$
  - 空间复杂度：$(O(1))$，固定大小26的数组，常量空间

## 💡学到的知识点

1. **数组哈希技巧**：当字符是连续的小写字母 a‑z，使用 `c-'a'` 将字符映射到0~25数组下标，效率远高于unordered_map。
2. 计数类哈希两种模式：
   - map：key存元素，value存出现次数；适合元素范围很大的场景。
   - 数组：下标代表元素，数组值存次数；适合元素范围小且连续。
3. 提前剪枝，减少不必要运算；本题字符串长度判断可以提前拦截一部分case。
4. 逻辑等价写法：数组既可以先判断计数是否为0再自减，也可以先自减再判断是否小于0，两种写法结果完全一致。

## ✨拓展思考（工程层面优化，不改变大O复杂度）

1. 使用`unordered_map`可以调用`reserve`预分配桶，减少rehash开销；但本题字符最多26个，收益很小。
2. 溢出风险：本题key为char，不存在数值溢出问题。
3. 如果题目改成包含全部ASCII字符，则数组大小要开到128；如果包含Unicode中文，则不能用数组哈希，必须使用unordered_map。
4. 也可以先遍历ransomNote统计，再拿magazine去抵消，逻辑等价。
